DRAGON BALL Z LO ES TODO

Servidor mínimo con Flask para la página fan de Dragon Ball Z.

Uso:
    1. crear el entorno virtual:         python -m venv (venv)
    2. activar el entorno virtual: venv\\Scripts\\activate
    (en caso tal de que salga un error al intentar activar el entorno virtal,introduzca el siguiente comando: Set-ExecutionPolicy Unrestricted -Scope Process
    3. instalar los requerimientos con este comando: pip install -r requirements.txt 
    4. iniciar el archivo .py: python app.py
